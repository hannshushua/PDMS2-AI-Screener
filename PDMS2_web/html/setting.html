在這裡指定哪一台實體攝影機是上方鏡頭，哪一台是旁邊鏡頭。設定會同步到本機與遠端資料庫，回到拍照頁面就會自動套用。

套用其他裝置的設定

從遠端資料庫選取其他裝置曾儲存的參數，帶入後仍需按「儲存設定」才會生效。

  • 建議先把上方與旁邊設定成不同的編號，避免拍照流程用到同一台攝影機。
  • 如果你的電腦只有一台攝影機，也可以先保留預設值 0 / 1，再依實際硬車調整。
  • 設定會同步保存到本機與遠端資料庫，重開頁面或重啟服務後都會保留。
