# PDMS-2 臨床導引與發展背景知識庫

本文件整合了 PDMS-2 的核心指標解釋、計分規則及臨床應用實證，作為 RAG 系統的背景知識參考。

---

## 1. 核心指標解釋 (Composites)
PDMS-2 的精細動作指標主要包含以下部分：
- **物件操作 (Object Manipulation)**：幼兒對球類的操控與手眼協調能力。
- **精細動作能力 (Fine Motor Quotient, FMQ)**：結合了抓握（Grasping）與視覺動作整合（Visual-Motor Integration）的綜合分數。

## 2. 施測計分標準 (Basal and Ceiling)
- **2 分**：表現完全符合精熟標準。
- **1 分**：表現接近標準但未完全達成。
- **0 分**：表現明顯未達標準。
- **基礎分 (Basal)**：連續三個項目獲得 2 分。
- **最高分 (Ceiling)**：連續三個項目獲得 0 分。

## 3. 臨床應用與特殊族群實證
- **早產兒 (Preterm)**：PDMS-2 具備高敏感度，能檢測微小動作缺陷。即便無腦麻症狀，早產兒常在移動與固定子測驗落後。
- **唐氏症 (Down Syndrome)**：分數與 Bayley 量表高度相關，在物體操作落後最明顯。
- **腦性麻痺 (Cerebral Palsy)**：在雙側腦麻評估中具極高信度 (ICC > 0.90)，且對治療介入後的變化反應優異。

## 4. 居家訓練與發展建議方向
- **手部控制**：透過空中畫圖、手指畫、沙盤練習，降低紙筆壓力。
- **工具使用**：剪紙應依序「剪直線 -> 剪波浪線 -> 剪圓形/正方形」。
- **視覺動作整合**：利用積木拼圖、描邊貼貼樂、尋寶遊戲增加對形狀的認知與控制力。
